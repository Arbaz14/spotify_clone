A responsive, faithful web recreation of the Spotify music streaming interface built with vanilla JavaScript, modern CSS, and HTML5 Audio API.

---

## ✨ Features

- 🎧 **Interactive Audio Player:** Play, pause, skip, and scrub through tracks with real-time seek bar updates.
- 🎚️ **Volume & Playback Controls:** Seamless volume slider and song duration timestamps.
- 📱 **Responsive Interface:** Spotify-themed dark mode aesthetic with sidebar navigation, playlists, and album cards.
- ⚡ **Pure Vanilla Core:** Lightweight and fast with zero framework dependencies.

---

## 🛠️ Built With

- **HTML5:** Semantic markup structure and audio element integration.
- **CSS3:** Custom layout design, flexbox, CSS Grid, and custom scrollbars.
- **JavaScript (ES6+):** DOM manipulation, audio state management, and event handling.

---

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Arbaz14/spotify_clone.git
   cd spotify_clone
   ```

2. **Open in browser:**
   Simply double-click `index.html` or launch with Live Server in VS Code.
